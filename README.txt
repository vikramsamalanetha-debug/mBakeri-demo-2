M BAKERI SIGNATURE DEMO

Open index.html in a modern browser.

This is a concept/pitch demo created for LIT America. It uses public web imagery plus representative product photography to demonstrate the art direction. Before production, replace representative product photos with M Bakeri-owned originals and connect the order UI to the chosen POS/payment platform.

Demo features:
- Multi-page responsive website
- Musical entrance with sound/quiet choice
- Founder storytelling + owner interview link
- Menu filtering
- Product customization modal
- Cart stored locally in the browser
- Pickup-order concept
- Custom cake and catering intake flows

No real payments are processed.
